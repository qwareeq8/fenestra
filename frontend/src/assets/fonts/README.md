# WebCM font assets

This subset of the `web-computer-modern` package gives Fenestra the Computer Modern typography
shared with SCI Map, Skopia, and Sella. The application loads these files from its own bundle and
never fetches fonts at runtime.

- Package: `web-computer-modern@1.1.0-new-cm-7-0-2`.
- Original typeface: New Computer Modern 7.0.2.
- License: GUST Font License 1.0 or later, with LPPL 1.3c or later.

The subset holds the 10-point Sans faces at weights 400, 500, and 700, the Serif face at weight 400,
and the Mono faces at weights 400 and 700. `MANIFEST-WebCM.txt` is the conversion manifest from the
published package, and `GUST-FONT-LICENSE.txt` holds the license text. Keep the WebCM file names;
the license asks that converted faces keep the names assigned to them.
